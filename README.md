# GUI Based To-Do List Application Using Python

## Project Description
This is a simple GUI-based To-Do List application developed using Python and Tkinter.

The application helps users manage daily tasks by allowing them to:
- Add tasks
- Delete selected tasks
- Clear all tasks

The project is beginner-friendly and created for learning Python GUI programming.

---

## Features
- Add new tasks
- Delete selected task
- Clear all tasks
- User-friendly graphical interface
- Warning messages for empty inputs

---

## Technologies Used
- Python
- Tkinter
